# JANSETU-v3

Harkhand Innovation Connect is a digital platform that connects citizens' real-world problems with AI, universities, industry partners, and government authorities for collaborative solutions. It enables reporting, categorization, prioritization, routing, and tracking of civic issues.

## Development

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Notes

- Project created in workspace. To push to a remote, add a Git remote and run `git push`.
